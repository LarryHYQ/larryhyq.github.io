## 一、版本编号规则

| 变更类型 | 版本格式 | 示例 | 说明 |
| --- | --- | --- | --- |
| 大版本 | `X.0` | `3.0` | 整体改版或较大的功能体系调整；新的大版本直接从整数开始 |
| 功能 / 逻辑更新 | `X.Y beta` | `3.1 beta`、`3.2 beta` | 每个功能或逻辑点对应一个十分位迭代，带 `beta` 标记 |
| 小调整 | `X.Y` | `3.1` | 页面内容与格式（排版、样式、结构）的更新 |
| 微微调整 | `X.Y.Z` | `3.0.1`、`3.0.2` | CV 文件、新增博客、新增奖项等内容级更新 |

补充约定：

- 版本号只增不减；同一版本内的多次提交不单独编号，统一记录在对应版本的变更说明中。
- 大版本切换后，次版本重新从 `X.1` 开始计数。
- 每次提交在提交信息中注明版本号与变更类型，便于回溯，例如 `feat(xxx): 描述（3.2 beta）`。
- `beta` 标记仅用于功能 / 逻辑更新，内容与格式调整不带 `beta`。

**3.0 变更明细**

- **导航**：导航菜单当前页面状态指示；移动端导航样式与缓存清理。
- **作者资料**：社交图标改为 SVG；新增 DBLP、小红书、抖音链接；暖沙金访客地图并适配移动端；补充可访问性属性。
- **博客时间轴**：桌面端时间轴与移动端紧凑窄轴双模式；左滑展开手势；悬停与焦点导航；滚动手势与自动隐藏。
- **归档与脚本**：文章归档页重构；移除页脚；重构脚本加载结构；清理示例文件与 `.gitignore`。
- **构建修复**：修复 `docs` 文档中的 Liquid 标签导致 GitHub Pages 构建失败的问题；更新学术主页模板配置。
- **侧栏与滚动条**：桌面端侧栏随页面整体滚动；页面滚动条自动隐藏；左右区域独立滚动；统一桌面/移动断点（925 → 1024）；修复浏览器高度不足与缩放时的闪动、访客地图高度等问题。
- **荣誉奖项**：证书图片按原始比例自适应（3 / 4 / 4 张排版、同行等高、铺满整行）；移动端两列展示；奖项改为卡片式排版并按级别配色（国家级/国际级、省赛区、其他）。
- **一键置顶**：全站统一按钮，滚动时出现、停止后淡出；桌面端回到页面顶部并右缘对齐右侧目录轴；移动端回到本章标题，并跟随窄目录轴的显隐一起出现/消失。
- **版本记录**：新增本文件并在 README 中引用。
