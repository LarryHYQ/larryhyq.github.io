# 版本记录 · Version History

> LarryHYQ's Attic 个人主页的版本记录。当前版本：**4.0.3**（2026-10-24）

> 版本号与提交**一一对应**：每一条提交都有独立版本号，见「四、版本历史（逐条提交）」。

## 一、版本编号规则

| 变更类型 | 版本格式 | 示例 | 说明 |
| --- | --- | --- | --- |
| 微微调整 | `X.Y.Z` | `4.0.3` | 内容级更新：CV 文件、新增博客、新增奖项、图片、文案、文档等，修订号 +1 |
| 小调整 | `X.Y` | `4.1` | 页面内容与格式（排版、样式、结构）更新，次版本 +1 |
| 功能 / 逻辑更新 | `X.Y beta` | `3.13 beta` | 功能开发期的连续迭代，每次提交占用一个十分位；**连续 beta 结束后紧接着发布新的大版本** |
| 大版本 | `X.0` | `4.0` | 一轮 beta 开发完成后发布；整体改版或较大的功能体系调整 |

约定：

- 每一条提交对应一个独立版本号，只增不减；提交信息末尾标注该版本号。
- beta 可以连续出现；**连续的 beta 之后的第一个版本一定是新的大版本**，beta 更新只服务于该大版本发布。
- 大版本发布之后的内容 / 格式调整使用 `X.0.Z` / `X.Y`，随后再进入下一轮 beta。
- 历史提交的版本号按提交信息与改动类型自动归类；若某条归类与预期不符，可直接修改该行版本号（后续版本号同步顺延）。
