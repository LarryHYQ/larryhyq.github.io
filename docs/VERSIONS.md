## 一、版本编号规则

| 变更类型 | 版本格式 | 示例 | 说明 |
| --- | --- | --- | --- |
| 大版本 | `X.0` | `4.0` | 整体改版或较大的功能体系调整；新的大版本直接从整数开始 |
| 功能 / 逻辑更新 | `X.Y beta` | `4.1 beta`、`4.2 beta` | 每个功能或逻辑点对应一个十分位迭代，带 `beta` 标记 |
| 小调整 | `X.Y` | `4.1` | 页面内容与格式（排版、样式、结构）的更新 |
| 微微调整 | `X.Y.Z` | `4.0.1`、`4.0.2` | CV 文件、新增博客、新增奖项等内容级更新 |

约定：

- 版本号只增不减；同一版本内可包含多次提交，逐条提交的版本归属记录在「二、版本明细」中。
- 自 `4.0.1` 起，每次提交单独占用一个版本号，并在提交信息末尾标注，例如 `docs(files): 更新中文简历 PDF（4.0.2）`。
- 大版本切换后，次版本重新从 `X.1` 开始计数；`beta` 仅用于功能 / 逻辑更新。
