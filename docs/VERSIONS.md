## 一、版本编号规则

| 变更类型 | 版本格式 | 示例 | 说明 |
| --- | --- | --- | --- |
| 微微调整 | `X.Y.Z` | `4.0.6` | 内容级更新：CV 文件、新增/修改博客文章、新增论文、新增奖项、图片、文案、文档 → 修订号 +1 |
| 小调整 | `X.Y` | `4.1` | 页面内容与格式的更新：排版、样式、字体、章节改名、布局细节、修复类改动 → 次版本 +1 |
| 功能 / 逻辑更新 | `X.Y beta` | `2.11 beta` | **真正的新功能或新交互逻辑**（如新增一键置顶、目录轴/时间轴、导航状态、脚本行为等）→ 次版本 +1 并带 `beta` |
| 大版本 | `X.0` | `4.0` | 整体改版或较大功能体系调整 → 新大版本 |

约定：

- `beta` **只**用于功能 / 逻辑层面的新增或改进；内容更新（新增/修改博客、论文、图片等）、修复、章节改名、字体与样式调整都**不使用** `beta`。
- `beta` 不要求后接大版本；大版本由整体改版或功能体系调整触发。
- 每一条提交对应一个独立版本号，只增不减；提交信息末尾标注该版本号。
- 历史提交按提交信息与改动内容归类；若某条归类与预期不符，可直接修改该行版本号（后续版本号同步顺延）。

| 本次提交内容 | 版本示例 |
| --- | --- |
| 更新 CV、新增博客、新增论文/奖项、图片/文案、文档 | `4.0.7`、…（修订号 +1） |
| 页面内容与格式调整（排版、样式、字体、改名、修复） | `4.1`、`4.2` …（次版本 +1） |

| 整体改版或较大功能体系调整 | `5.0`（新大版本） |
